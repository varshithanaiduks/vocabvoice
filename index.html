Mastery is a practice estimate, not a formal language proficiency score. Progress is stored in this browser on this device.

VocabVoice is a learning prototype, not a certified language assessment. Sentence feedback uses transparent heuristics; it does not understand meaning like a human tutor or an AI language model.

Privacy & browser limitations

Vocabulary progress is stored in localStorage on this device. There is no VocabVoice account, application backend, analytics SDK or external AI API in this prototype.

When you use microphone recognition, your browser may process audio using a remote speech service. That processing is controlled by the browser/platform, not by VocabVoice. Use typed input if you do not want to use speech recognition.

Speech recognition is not supported in every browser. Chrome or Edge on a secure HTTPS page is recommended. Text-to-speech depends on voices installed on your device.
