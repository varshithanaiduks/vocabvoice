# VocabVoice

A lightweight, voice-first vocabulary learning prototype built for the Apna Product Operations application.

## Core loop

Introduce a word → hear it → speak a sentence → evaluate usage → adapt difficulty → reinforce weak words → review session.

## Privacy

No account, backend, analytics SDK, or external API key. Learning stats are stored in the browser with localStorage.

## Run

Open `index.html` in a modern browser. Chrome/Edge desktop are recommended for Web Speech API support.
